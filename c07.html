문제 1 · 정수론 + 파일 입력 + 예외 처리

소수 관측 데이터 파일에서 잘못된 값 찾아내기

문제 상황

과학고 수학 탐구반은 여러 자연수를 파일에 저장해 두고, 그 수가 소수인지 합성수인지 분류하려고 합니다. 그런데 데이터 파일에는 실수, 음수, 빈칸, 문자처럼 분석할 수 없는 값이 섞여 있습니다.

연구팀은 파일에서 한 줄씩 값을 읽고, 올바른 자연수이면 소수 판별 대상으로 삼고, 잘못된 값이면 프로그램이 멈추지 않도록 예외 처리를 해야 합니다.

④ 정상 결과와 오류를 구분해 저장하면 나중에 결과 분석과 데이터 정제를 효율적으로 할 수 있습니다.
문제 2 · 해석학 + 물리학 + 파일 출력

낙하 실험 측정값 저장과 이상값 처리

문제 상황

물리학 탐구반은 공의 낙하 실험을 하며 시간과 위치를 측정했습니다. 위치 데이터로부터 평균 속도를 추정하려고 하지만, 센서 오류로 말이 안 되는 값이 하나 포함되어 있습니다.

연구팀은 정상 측정값은 결과 파일에 저장하고, 이상값은 오류 파일에 기록하려고 합니다. 이는 해석학에서 함수의 변화율을 관찰할 때도 중요한 데이터 정제 과정입니다.

시간 t(s)0.00.10.20.30.4
위치 y(m)0.000.050.20-9990.78

여기서 -999는 실제 위치가 아니라 센서가 실패했을 때 표시한 오류값입니다.

③ 정상 데이터만 저장하면 그래프 작성, 변화율 추정, 실험 보고서 작성에서 신뢰도가 높아집니다.
④ 해석학의 변화율과 극한은 작은 차이에도 민감하므로 오류값을 제거하지 않으면 잘못된 결론을 낼 수 있습니다.
문제 3 · 생명과학 + 화학 + 지구과학 + 예외 처리

미세먼지와 호흡기 건강 데이터 통합 파일 만들기

문제 상황

환경보건 연구팀은 미세먼지 농도, 기온, 호흡기 증상 신고 수를 한 파일로 통합하려고 합니다. 그런데 서로 다른 기관에서 받은 파일은 형식이 다릅니다.

어떤 파일에는 날짜가 빠져 있고, 어떤 파일에는 농도 단위가 다르며, 어떤 줄에는 숫자 대신 “측정불가”라는 문자가 들어 있습니다.

자료예시 값문제
미세먼지78 μg/m³정상
기온측정불가숫자 아님
호흡기 신고32건정상

연구팀은 잘못된 줄은 멈추지 않고 오류 목록에 기록한 뒤, 정상 자료만 통합 파일로 저장하려고 합니다.

정답 및 해설

② 날짜가 없으면 어느 날의 미세먼지와 건강 신고인지 연결할 수 없어 시계열 분석이 불가능해집니다.
③ 정상 데이터 분석과 오류 데이터 수정 작업을 분리할 수 있어 연구의 신뢰성과 효율성이 높아집니다.
④ 실제 과학 데이터는 누락값과 형식 오류가 많기 때문에, 프로그램이 멈추지 않고 오류를 기록하며 분석을 계속하는 능력이 중요합니다.
총정리
파일 입출력은 데이터를 읽고 저장하는 과정이며, 예외 처리는 잘못된 값이나 누락값이 있어도 전체 분석이 멈추지 않게 하는 안전장치입니다. 정수론·해석학·물리·화학·생명·지구과학 연구에서는 데이터의 양이 많고 오류가 섞일 수 있으므로, 정상 결과 파일과 오류 기록 파일을 분리하는 사고가 매우 중요합니다.
