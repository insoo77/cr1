문제 1 · 실생활 + 스포츠 과학 + 큐 Queue

경기 중 부상 선수 응급처치 순서 관리

문제 상황

학교 스포츠 과학 대회에서 여러 선수가 동시에 부상을 입었습니다. 의료 지원팀은 선수가 도착한 순서대로 처치하는 큐(Queue) 구조를 기본으로 사용합니다.

큐는 먼저 들어온 사람이 먼저 나가는 구조입니다. 다만 생명 위험이 의심되는 경우에는 별도 응급 판단이 필요합니다.

문제 2 · 화학 + 생명과학 + 스택 Stack

실험실 시료 보관과 꺼내기 순서

문제 상황

생명과학 실험실에서 세포 배양 시료를 냉동 보관함에 차례대로 쌓아 넣었습니다. 보관함 구조상 맨 위에 있는 시료부터 꺼낼 수 있습니다.

이런 구조를 스택(Stack)이라고 합니다. 스택은 나중에 들어온 것이 먼저 나가는 구조입니다.

② A 시료를 먼저 꺼내고 싶다면 어떤 문제가 생기는가?
③ 화학·생명과학 실험에서 스택 구조가 적합하지 않은 경우를 설명하시오.
정답 및 해설
① D → C → B → A 순서입니다.
② A는 맨 아래에 있으므로 위에 있는 D, C, B를 먼저 꺼내야 합니다.
③ 오래된 시료를 먼저 사용해야 하는 실험, 온도 변화에 민감한 시료 관리, 유효 기간이 중요한 시료 관리에는 단순 스택보다 날짜 기준 정렬이나 큐 구조가 더 적합할 수 있습니다.
문제 3 · 물리학 + 지구과학 + 트리 Tree

기상 위험 판단 의사결정 트리

문제 상황

기상 관측소는 태풍 접근 여부를 판단하기 위해 풍속, 기압, 강수량 데이터를 사용합니다. 연구팀은 여러 조건을 단계적으로 판단하는 트리(Tree) 구조를 만들었습니다.

조건판단
풍속 ≥ 25 m/s강풍 위험
기압 ≤ 980 hPa태풍 가능성 증가
강수량 ≥ 80 mm침수 위험

현재 관측값은 풍속 28 m/s, 기압 975 hPa, 강수량 60 mm입니다.

② 최종 판단은 강풍·태풍 주의입니다. 침수 위험 기준은 넘지 않았습니다.
③ 조건을 단계별로 나누어 복잡한 기상 데이터를 이해하기 쉽게 판단할 수 있습니다.
④ 실제 날씨는 해수면 온도, 지형, 대기 흐름, 습도 등 많은 변수가 얽혀 있어 단순 트리만으로는 완벽한 예측이 어렵습니다.
총정리
자료구조는 데이터를 어떻게 담고, 어떤 순서로 꺼내고, 어떤 관계로 연결할지 정하는 방법입니다. 큐는 대기열, 스택은 쌓기 구조, 트리는 단계적 판단 구조에 잘 어울립니다. 과학고 창의력 문제에서는 자료구조를 단순 암기가 아니라 실제 과학 데이터와 의사결정에 연결해 해석하는 능력이 중요합니다.
