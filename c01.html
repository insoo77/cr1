문제 1 · 공학 + 실생활

스마트 공장 로봇 팔의 작업 모드 바꾸기

문제 상황

스마트 공장의 로봇 팔은 네 가지 기능을 0과 1로 기억합니다. 1은 기능이 켜진 상태, 0은 기능이 꺼진 상태입니다.

현재 로봇 팔의 상태는 1010입니다. 공장 관리자는 작업 순서를 바꾸기 위해 이 상태를 왼쪽으로 1칸 시프트했습니다.

왼쪽 시프트는 왼쪽으로 한 칸 밀고, 오른쪽 빈칸에는 0이 들어오는 이동입니다.

문제 2 · 물리학 + 천문학 + 우주공학

우주 탐사선 태양 전지판 각도 조절

문제 상황

우주 탐사선은 태양빛을 잘 받기 위해 태양 전지판의 방향을 조절합니다. 네 개의 비트는 각각 특정 각도 모드를 나타냅니다.

현재 탐사선의 태양 전지판 상태는 1000입니다. 태양빛의 방향이 바뀌자 탐사선은 상태를 오른쪽으로 1칸 시프트했습니다.

문제 3 · 생명과학 + 화학 + 지구환경

환경 DNA 센서의 위험 신호 이동

문제 상황

한 연구팀은 강물 속 미생물 DNA와 화학 오염 신호를 동시에 관찰하는 센서를 만들었습니다. 네 개의 비트는 서로 다른 위험 신호를 나타냅니다.

현재 센서 상태는 0011입니다. 연구팀은 위험 신호를 상위 경보 단계로 올리기 위해 상태를 왼쪽으로 2칸 시프트했습니다.

정리
비트 시프트는 단순한 숫자 계산이 아니라, 로봇 제어·우주 탐사·환경 센서처럼 여러 상태를 빠르게 바꾸는 데 사용할 수 있습니다. 과학고 창의력 문제에서는 “0과 1의 이동이 실제 장치나 과학 현상에서 어떤 의미를 가지는가?”를 해석하는 능력이 중요합니다.
